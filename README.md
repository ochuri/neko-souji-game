# ねこ毛、いただきます。

ロボット掃除機の床すれすれ一人称視点で、60秒間に猫毛を集めるスマホ向けWebゲームです。

## 遊び方

- 左のスティックで前後移動・旋回
- 右の「吸」ボタンを押している間、正面近くの猫毛を吸引
- 虎太郎、ゆらぎ、ハイハイする赤ちゃん、家具の脚を避ける
- ソファ下の狭い隙間には掃除機だけが入れる
- 猫のゲロに触れるとその時点で終了
- ロボット掃除機の向きに合わせて、3Dの部屋を途切れず毎フレーム見回せる

キーボードでは `WASD` / 矢印キーで移動、スペースで吸引できます。

## アートパイプライン

虎太郎・ゆらぎ・赤ちゃんは、国産インディーゲーム風の輪郭と限定色で描いた `public/assets/characters-master.png` の canonical master から描画しています。移動時の揺れ・向きは実行時変換だけで表現し、キャラクターごとに独立生成したアニメーションフレームは使用していません。

室内は Three.js の単一3D空間として構築しています。ロボット掃除機の床すれすれカメラが位置と向きを毎フレーム補間するため、背景画像の切り替えやクロスフェードはありません。家具・床・壁・猫毛・障害物は同じ座標空間に存在し、ソファ下の隙間や椅子脚のスラロームもそのまま走行できます。遠景は同じゆめかわドット絵室内の本番アートを8枚の3D環境面へ貼り、旋回時にも面そのものを連続描画します。

## 検証

```sh
npm test
npm run build
```

静的ファイルだけで動作するため、`index.html` を配信できる任意の静的ホスティングで公開できます。
