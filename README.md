# ねこ毛、いただきます。

ロボット掃除機の床すれすれ一人称視点で、60秒間に猫毛を集めるスマホ向けWebゲームです。

## 遊び方

- 左のスティックで前後移動・旋回
- 猫毛の上を走ると、ロボット掃除機が自動で吸引
- 虎太郎、ゆらぎ、ハイハイする赤ちゃん、家具の脚を避ける
- ソファ下や机下の狭い隙間には掃除機だけが入れる
- 猫のゲロに触れるとその時点で終了
- ロボット掃除機の向きに合わせて、3Dの部屋を途切れず毎フレーム見回せる

キーボードでは `WASD` / 矢印キーで移動できます。登場するのは虎太郎・ゆらぎ・赤ちゃんのうち毎回2人で、再開するたびに組み合わせが変わります。

## アートパイプライン

虎太郎・ゆらぎ・赤ちゃんは、国産インディーゲーム風の輪郭と限定色で描いた `public/assets/characters-master.png` の canonical master から描画しています。移動時の揺れ・向きは実行時変換だけで表現し、キャラクターごとに独立生成したアニメーションフレームは使用していません。

室内は Three.js の単一3D空間として構築しています。ロボット掃除機の床すれすれカメラが位置と向きを毎フレーム補間するため、背景画像の切り替えやクロスフェードはありません。家具・床・壁・猫毛・障害物は同じ座標空間に存在し、ソファ下・机下の隙間や椅子脚のスラロームもそのまま走行できます。猫毛は短いふわ毛、大きな毛玉、長く絡んだ束を混在させ、猫ごとの色味も描き分けています。遠景は同じゆめかわドット絵室内の本番アートを円筒状の3D環境へ貼り、旋回時にも途切れず連続描画します。

## 検証

```sh
npm test
npm run build
```

静的ファイルだけで動作するため、`index.html` を配信できる任意の静的ホスティングで公開できます。
