# ねこ毛、いただきます。

ロボット掃除機の床すれすれ一人称視点で、60秒間に猫毛を集めるスマホ向けWebゲームです。

## 遊び方

- 左のスティックで前後移動・旋回
- 猫毛の上を走ると、ロボット掃除機が自動で吸引
- 猫がときどき「かいかい」すると、その場に新しい猫毛が落ちる
- 虎太郎、ゆらぎ、ハイハイする赤ちゃん、家具の脚を避ける
- ソファ下や机下の狭い隙間には掃除機だけが入れる
- 猫のゲロに触れるとその時点で終了
- ロボット掃除機の向きに合わせて、3Dの部屋を途切れず毎フレーム見回せる

キーボードでは `WASD` / 矢印キーで移動できます。登場するのは虎太郎・ゆらぎ・赤ちゃんのうち毎回2人で、再開するたびに組み合わせが変わります。

## アートパイプライン

虎太郎・ゆらぎ・赤ちゃんは、国産インディーゲーム風の大頭身・限定色・64px基準ドットで描いた `public/assets/characters-master-v3.png` の canonical master から描画しています。移動時の揺れ・向きは実行時変換だけで表現し、キャラクターごとに独立生成したアニメーションフレームは使用していません。

室内は Three.js の単一3D空間として構築しています。床・壁・窓・ソファ・机・椅子・収納・植物はすべて実座標を持つ3D物体で、背景画に描かれただけの家具や進めない偽の場所はありません。ロボット掃除機の床すれすれカメラが位置と向きを毎フレーム補間し、ソファ下・机下の隙間や椅子脚のスラロームも同じ空間内をそのまま走行できます。スティックは倒した方向を固定目標にして旋回しながら前進するため、その場で回り続けません。猫毛は短いふわ毛、大きな毛玉、長く絡んだ束を混在させ、猫ごとの色味も描き分けています。

## 検証

```sh
npm test
npm run build
```

静的ファイルだけで動作するため、`index.html` を配信できる任意の静的ホスティングで公開できます。
